# AI마스터스쿨 숏폼 안내서 — 노트북 채팅 하나로 끝까지

> 이 문서는 Gemini 노트북의 **자료**로 넣어 두고, 그 노트북의 채팅에서 숏폼 한 편을 처음부터 끝까지 만드는 안내서입니다.
> 30초~1분 세로(9:16) 숏폼을 **무료 구글 계정 + 컴퓨터(Chrome)**로 만듭니다.
> 기준일: 2026년 11월 3일(무료 계정 화면으로 확인). 메뉴와 무료 한도는 바뀔 수 있습니다 — 화면과 다르면 화면이 맞습니다.
> 보고 따라 하는 그림 안내: https://toddoward.github.io/shortform-guide/

---

## 0. 이 노트북에서 Gemini가 지킬 진행 규칙

1. **한 채팅에서 끝까지 간다.** 사용자에게 새 채팅을 열라고 말하지 않는다. 음악도 이 채팅에서 만든다.
2. **글로 하는 단계는 바로 결과를 쓴다.** 지시문을 보여 주고 붙여 넣으라고 하지 않는다. 사용자가 "다음"이라고 하면 다음 단계의 결과를 쓴다.
3. **다른 곳에 넣을 글만 코드 블록으로 준다.** AI Studio(목소리) · Flow(사진 · 영상 조각) · 「음악 만들기」 · 편집 앱(자막)에 붙여 넣을 글이다. 코드 블록 하나 = 한 번에 붙여 넣을 덩어리 하나.
4. **모든 답의 형식**

```text
[N/8 · 단계 이름] (이야기 숏폼 또는 공학 숏폼)
지금 할 일: 한 문장

(결과 또는 붙여 넣을 글)

어디서 무엇을 누르나: 이 단계의 버튼 순서 (§3~§10에 적힌 그대로)
확인할 것: 두세 개
다음은 N+1 · 단계 이름 — (그 단계를 시작하는 방법 한 줄) 끝나면 "다음"이라고 말해 주세요.
```

5. **첫 답**: 사용자가 주제를 말하면 갈래(이야기 · 공학)를 정하고, **아래 「8단계 지도」 표를 반드시 먼저 보여 준 뒤** 바로 1단계 결과를 쓴다. 갈래를 말하지 않았으면 주제를 보고 고른 뒤 한 줄로 알려 준다.
6. **고칠 때는 고칠 곳만.** "S03만 다시"라고 하면 그 장면만 다시 쓰고 나머지는 그대로 둔다.
7. **사실을 지어내지 않는다.** 이야기에 없는 사실 · 숫자 · 실존 인물 · 실제 가게 이름은 쓰지 않는다. 모르는 것은 [확인 필요]. 공학 숫자는 출처가 있는 것만 쓰고 출처는 링크로 단다.
8. **쉬운 말, 짧은 문장.** 버튼 이름은 이 문서에 적힌 그대로 「」 안에 쓴다. 기술 용어를 쓰지 않는다. 답에 [cite] 같은 참고 표시를 넣지 않는다.
9. **파일로 저장하는 것은 사진 · 소리 · 영상뿐이다.** 대본 · 장면표 같은 글은 이 채팅에 남겨 두고, 표나 글을 파일로 저장하라고 하지 않는다.

### 8단계 지도 (첫 답에 이 표를 보여 준다)

| 단계 | 하는 일 | 어디서 | 남는 것 |
|---|---|---|---|
| 1 | 대본 | 이 채팅 (공학은 조사 선택) | 대본 (채팅에 남음) |
| 2 | 목소리 | AI Studio | 목소리 파일 |
| 3 | 장면 설계 | 이 채팅 | 장면표 (채팅에 남음) |
| 4 | 장면 사진 | Flow 「이미지」 | 사진 (Flow 프로젝트에 남음) |
| 5 | 영상 조각 (선택) | 같은 Flow 프로젝트 「동영상」 | 영상 조각 → 사진 · 영상 내려받기 |
| 6 | 배경음악 | 이 채팅 + 「음악 만들기」 | 음악 파일 |
| 7 | 합치기 | 편집 앱 | 완성 영상(mp4) |
| 8 | 제목 · 올리기 전 확인 | 이 채팅 | 제목 · 설명 |

## 1. 두 갈래 — 무엇이 다른가

| | 이야기 숏폼 | 공학 숏폼 |
|---|---|---|
| 주제 | 내가 본 장면 · 겪은 하루 · 남기고 싶은 감정 | "왜 그럴까?" 질문 하나 |
| 주제 예 | 우리 동네 단골 빵집의 이른 아침 / 퇴근길 창밖의 저녁 한강 | 전동차 바퀴는 왜 원뿔 모양일까? / 달리던 전동차는 어떻게 멈출까? |
| 대본 흐름 | 궁금한 첫 줄 → 기대나 어려움 → 풀림 → 마무리 한 마디 | 질문 → 이대로면 생기는 문제 → 결정적인 설계 → 원리 → 얻는 것과 한계 |
| 사실 확인 | 필요 없음 (내 이야기) | **필수** — 숫자 · 원리는 출처를 연다. 조사(Deep Research)는 선택 |
| 사진 | 장면마다 한 장 (4~6장) | 장면마다 **짝**: 「빈 사진」 + 같은 사진에 화살표 · 이름표를 더한 「설명 사진」 |
| 영상 조각 (선택) | 사진에서 이어지는 8초 | 빈 사진에서 시작해 설명 사진에서 끝나는 4초 (「시작」 · 「종료」) |
| 목소리 말투 | 친구에게 말하듯 따뜻하고 차분하게 | 다큐 해설자처럼 또렷하고 차분하게 |
| 음악 | 감정을 따라가는 잔잔한 연주곡 | 긴장이 커지다 원리에서 풀리는 연주곡 |

**고르는 법**: 내 경험이나 풍경이면 이야기, 원리를 설명하고 싶으면 공학. 처음이면 이야기 숏폼이 빠릅니다(사진이 절반).

## 2. 노트북 준비 (처음 한 번만)

1. gemini.google.com → 왼쪽 「새 노트북」 → 이름 쓰기(예: 숏폼 만들기) → 오른쪽 화살표
2. 「소스 추가」 → 「텍스트 복사됨」 → 이 안내서 붙여 넣기 → 「텍스트 추가」 (또는 「파일 업로드」로 이 파일)
3. 오른쪽 위 「⋮」 → 「노트북 설정」 → 「노트북 메모리 사용」 끄기 → 「요청 사항」에 진행 규칙 붙여 넣기 → 「저장」
4. 노트북 입력창(「Gemini에게 물어보기」)에 첫 말을 씁니다.

```text
주제는 "[내 주제]"이고 [이야기 / 공학] 숏폼으로, 길이는 [30초~1분]으로 만들고 싶어. 8단계 지도를 보여 주고 1단계를 해 줘.
```

**다음 숏폼을 만들 때**: 같은 노트북을 열고 입력창에 다시 첫 말을 씁니다(노트북 안의 새 채팅). 노트북 준비는 다시 하지 않습니다. Flow는 「새 프로젝트」를 하나 더 만듭니다.

## 3. 1단계 · 대본 (이 채팅)

### 이야기 숏폼 — Gemini가 쓸 것

- **이야기 네 줄**: 남길 감정 한 단어 / 주인공(사람이면 얼굴이 보이지 않게 — 뒷모습 · 손 · 실루엣, 사물이면 그 사물) / 장소 · 계절 · 하루 중 시간 / 마지막에 남길 한 장면과 한 마디
- **장면별 대본**: 장면 4~6개(S01~). 장면마다 길이(초) · 감정 · **내레이션 한두 문장**. 합쳐서 사용자가 말한 길이(30초~1분).
- **대본 흐름**: 처음 3초 안에 궁금하게 만드는 한 줄 → 전체의 3분의 1까지 기대나 어려움을 키우고 → 나머지에서 풀어 주고 → 짧은 마무리 한 마디. 문장은 짧게, 문장마다 한 걸음씩.

### 공학 숏폼 — Gemini가 쓸 것

- **네 문장**: 핵심 질문 / 핵심 원리 / 화면에서 보일 흐름이나 힘 / 이것만의 특징
- **장면별 대본**: 장면 4~6개. 처음 3초에 질문 → 전체의 3분의 1까지 문제와 모순을 키움 → 설계와 물리 작용이 문제를 해결 → 현실의 대가나 한계 한 줄 → 짧은 결론
- **사실 표시**: 숫자와 원리마다 출처 링크. 확정된 사실 · 논쟁 중인 해석 · 영상을 위해 단순화한 부분을 나눠 표시. 출처 없는 숫자는 [확인 필요]

### 조사하고 쓰고 싶을 때 (공학, 선택)

입력창 「+」 → 「Deep Research」 켜기 → 주제 보내기 → 조사 계획이 나오면 시작 → 보통 5~10분. 끝나면 「Deep Research」를 끄고 "조사 결과로 1단계 해 줘"라고 말합니다. 무료 계정은 사용자가 많을 때 못 쓸 수 있습니다 — 그때는 조사 없이 진행합니다.

### 사용자가 확인할 것

이야기: 처음 3초가 궁금한가 · 문장마다 새 내용이 나오나 · 마지막 한 마디가 남나
공학: 위에 더해 숫자마다 출처를 내가 열어 봤나 · 한계가 한 줄 있나
고칠 때: "S02 문장을 더 짧게", "마지막 한 마디를 바꿔 줘"처럼 고칠 곳만 말합니다.

## 4. 2단계 · 목소리 (AI Studio)

목소리를 사진보다 먼저 만듭니다. 장면 길이는 **실제 목소리 길이**로 정하기 때문입니다.

### Gemini가 줄 것 (코드 블록 둘)

1. **읽을 대본**: 장면 내레이션만 순서대로. 장면 사이에 `<short pause>`, 숨을 고를 곳 한 군데에 `<long pause>`. 숫자와 영어는 소리 나는 대로 한글로(1/20 → 이십분의 일).
2. **말투(Style) 한 줄**: 20자 안팎. 이야기 — `친구에게 말하듯 따뜻하고 차분하게` / 공학 — `다큐 해설자처럼 또렷하고 차분하게`
3. 목소리 추천: **Enceladus** (다른 목소리를 원하면 성격 낱말 둘, 예: Warm · Clear)

### 사용자가 누를 것 (화면은 영어)

1. aistudio.google.com/generate-speech → 「Create new dialog」
2. 가운데 글 상자에 **읽을 대본** 붙여 넣기
3. 글 상자 위 「Speaker 1 - 이름 ▾」 → 오른쪽 「Search 2,000+ voices」에 Enceladus → 누르기
4. 「Style ▾」 → 「Describe the voice style」 칸에 **말투** 붙여 넣기
5. 오른쪽 아래 「Run」 → ▶ 듣기 → ⬇ 내려받기
6. **실제 길이(초)**를 채팅에 알려 줍니다: `목소리 길이는 48초야. 다음`

확인할 것: 발음이 틀린 단어가 없나(있으면 대본에서 소리 나는 대로 고쳐 다시) · 장면이 바뀔 곳에서 쉬나 · 말한 길이 안인가

## 5. 3단계 · 장면 설계 (이 채팅)

### Gemini가 쓸 것

**룩 바이블** — 모든 사진에 글자 하나 바꾸지 않고 붙일 문단(코드 블록 하나):
- 이야기: 질감(포토리얼 시네마틱 사진, 35mm 필름 느낌의 옅은 입자) · 빛(자연광, 하루 중 시간 하나, 빛 방향 하나, 빛의 질 하나, 그림자 방향) · 공기(먼지 입자 · 옅은 안개 · 김 중 하나) · 색(주된 색 둘 + 포인트 하나) · 카메라(35mm 안팎, 눈높이 또는 조금 낮게, 얕은 심도) · 주인공 고정 묘사(옷 · 색 · 소품 · 체형 한 줄) · 넣지 않는 것(글자 · 숫자 · 간판 글씨 · 로고 · 워터마크 · 얼굴 정면 · 유리에 비친 얼굴 · 과한 HDR · 네온 · 판타지 효과)
- 공학: 질감(포토리얼 시네마틱 3D 공학 다큐멘터리) · 대상(형상 · 시대 · 재료 · 색 한 줄로 고정) · 빛(시간대 · 방향 · 질 하나씩) · 카메라(전경 · 중경 · 배경의 깊이, 5~15도 움직일 여유) · 넣지 않는 것(글자 · 숫자 · 기호 · 치수선 · 화살표 · 지시선 · 공식 · 차트 · 로고 · 워터마크 · 네온 · 판타지 효과 · 사람 얼굴)

**장면표** — 실제 목소리 길이를 장면 수로 나눠, 장면마다:
- 번호(S01~) · 길이(초) · 이 장면의 대본 구절
- 화면: 전경 · 중경 · 배경에 무엇이 있는지 · 이 장면의 빛 · 카메라 거리와 높이
- 움직일 것 하나(영상 조각을 만들 때 — 사진 안에 이미 있는 것: 걷는 발걸음, 오르는 김, 흔들리는 잎, 바퀴의 회전)
- 공학만: 설명 사진에 넣을 것 — 작은 한글 이름표 1~3개(한 개 2~6글자), 숫자 0~1개, 화살표가 가리킬 부품과 방향

장면끼리는 같은 장소 · 같은 시간대 · 같은 주인공(대상)으로 이어 가고, 카메라 거리는 앞 장면과 겹치지 않게 바꾼다. 같은 말을 하는 장면은 만들지 않는다.

끝 줄: "다음은 4 · 장면 사진 — Flow에 붙여 넣을 사진 주문을 드립니다. '다음'이라고 말해 주세요."

## 6. 4단계 · 장면 사진 (Flow 「이미지」)

사진은 Flow 프로젝트 하나에서 만들고, 고치고, 그대로 영상 조각의 시작 프레임으로 씁니다. 내려받았다가 다시 올리지 않습니다.

### Gemini가 줄 것 — 장면마다 코드 블록 하나

- **사진 주문**: `[S01] 세로 9:16 독립 사진 한 장, 콜라주나 분할 화면 없이.` → 이 장면의 화면(전경 · 중경 · 배경) → 이 장면의 빛 → 카메라 → 룩 바이블 전문 → `앞 장면과 같은 주인공 · 장소 · 시간대 · 빛 방향을 이어 간다.`
- 공학은 장면마다 **설명 주문**을 하나 더: `[S01 설명] 붙인 사진을 그대로 편집한다.` → 카메라 · 구도 · 형상 · 조명 · 배경은 그대로 → 실제 3D 공간에 붙은 화살표와 지시선(실제 부품에서 시작, 원근을 따름) → 색: 일반 흐름은 청록, 위험 · 압력은 주황에서 빨강, 핵심 숫자는 금색, 지시선은 옅은 청백색 → 작은 한글 이름표 1~3개 · 숫자 0~1개만, 큰 제목과 문장은 넣지 않는다 → **화면 아래 4분의 1은 자막 자리로 비운다** → 대본에 있는 숫자와 단위만 쓴다.

### 사용자가 누를 것

1. flow.google.com → 「새 프로젝트」
2. 입력창 아래 「에이전트」가 하얗게 켜져 있으면 눌러 끄기
3. 입력창 오른쪽 아래 설정 칩 → 「이미지」 → 「9:16」 → 「x2」 ("생성 시 0 크레딧" — 사진은 크레딧을 쓰지 않습니다)
4. 입력창에 **[S01] 사진 주문** 붙여 넣기 → 오른쪽 화살표 (Enter 대신 화살표를 누릅니다)
5. 두 장 중 마음에 드는 사진의 「⋮」 → 「이름 바꾸기」 → `S01`
6. `S02` · `S03` … 마지막 장면까지 같은 방법

**고칠 때**: 사진을 누르면 크게 열립니다 → 아래 「어떤 내용을 변경하려 하시나요?」에 고칠 점(예: `유리에 비친 얼굴을 지워 줘`) → 오른쪽 화살표 → 「완료」. 고친 사진은 원래 사진 자리에 겹쳐 쌓입니다.

**공학 — 설명 사진 만들기**: 빈 사진(S01)의 「⋮」 → 「프롬프트에 추가」 → 입력창에 **[S01 설명] 주문** 붙여 넣기 → 오른쪽 화살표 → 새 사진의 「⋮」 → 「이름 바꾸기」 → `S01 설명`. (사진을 눌러 고치면 빈 사진이 사라지고 겹쳐 쌓이므로, 설명 사진은 이 방법으로 따로 만듭니다.)

### 사용자가 확인할 것

이야기: 같은 주인공(옷 · 소품)인가 · 빛 방향과 시간대가 같은가 · 글자 · 로고가 없는가 · 얼굴(유리에 비친 얼굴 포함)이 없는가 · 세로인가
공학: 위에 더해 설명 사진이 빈 사진과 같은 구도인가 · 화살표 방향이 맞나 · 한글 이름표가 깨지지 않았나 · 아래 4분의 1이 비었나

어긋난 장면은 채팅에 말합니다: `S02 사진 주문을 다시 써 줘. 앞 사진과 같은 주인공 옷차림, 같은 빛 방향으로.`

## 7. 5단계 · 영상 조각 (선택, 같은 Flow 프로젝트 「동영상」)

사진만으로도 영상이 됩니다 — 편집 앱이 사진을 천천히 확대해 움직임을 줍니다. 크레딧이 남으면 영상 조각을 만듭니다.

### Gemini가 줄 것 — 장면마다 코드 블록 하나

- 이야기: `[CLIP01 · S01] 시작 프레임의 사진에서 이어지는 8초, 컷 없는 한 숏.` → 카메라: 아주 천천히 하나만(천천히 다가가기 · 옆으로 천천히 흐르기 · 살짝 돌아가기 · 고정) → 장면 속 움직임: 장면표의 "움직일 것" 하나 → 시간 흐름: 처음 1초는 거의 멈춤 → 1~7초 천천히 → 마지막 1초 멈춤 → `빛과 색, 주인공의 옷차림은 시작 프레임 그대로 유지.` → `넣지 않는 것: 새 사람이나 사물 등장, 얼굴 정면, 모양이 녹아내리듯 바뀌는 것, 빠른 회전, 글자 · 자막 · 로고, 대사.`
- 공학: `[CLIP01 · S01] 시작: S01 · 종료: S01 설명. 4초, 컷 없는 한 숏.` → 빈 사진 장면 위에서 그래픽이 새로 그려져 끝 프레임에 닿는다: 0~0.4초 빈 사진만 → 0.4~0.9초 기준점 → 0.9~1.7초 지시선 · 화살표 몸통이 자람 → 1.7~2.6초 이름표와 숫자 · 화살촉 → 2.6~3.4초 힘과 흐름의 빛이 화살표를 따라 이동 → 3.4~4초 끝 프레임에 멈춤. 카메라는 5~15도 하나만. 넣지 않는 것: 화면 전체가 한꺼번에 나타나는 효과, 떨리는 글자, 거꾸로 가는 화살표, 구조가 녹아 변하는 것, 대사 · 음악 · 로고.

### 사용자가 누를 것

1. 같은 프로젝트에서 설정 칩 → 「동영상」 → 「프레임」 → 「9:16」 → 「Omni 1.1 Flash」 → 「720p」 → 길이(이야기 「8초」 · 공학 「4초」) → 「x1」
2. 입력창 위 「시작」 → 목록에서 `S01` → 「프롬프트에 추가」 (공학은 「종료」 → `S01 설명` → 「프롬프트에 추가」)
3. **[CLIP01] 주문** 붙여 넣기 → 오른쪽 화살표 → 1분 남짓
4. 다음 장면도 같은 방법

**무료 크레딧(하루 50)**: 「720p」 「8초」 「x1」 = 12크레딧(하루 4조각) · 「720p」 「4초」 = 7크레딧(하루 7조각). 만들기 전에 "생성 시 N 크레딧"을 확인합니다. 「x2」면 두 배가 듭니다.

### 내려받기 — 편집 앱에 넣을 것

- 영상 조각이 있는 장면: 영상의 「⋮」 → 「다운로드」 → 「720p 원본 크기」 → 파일 이름 `01_S01.mp4`
- 영상 조각이 없는 장면: 사진(공학은 설명 사진)의 「⋮」 → 「다운로드」 → 「1K 원본 크기」 → 파일 이름 `02_S02.png`

확인할 것: 첫 장면이 사진과 같은가 · 카메라가 한 방향으로 천천히 움직이나 · 모양이 녹거나 바뀌지 않나 · 새 사람이나 글자가 생기지 않나

## 8. 6단계 · 배경음악 (이 채팅 + 「음악 만들기」)

### Gemini가 줄 것 — 음악 주문 코드 블록 하나

첫 줄 `연주곡을 만들어 줘.` → 장르 · 템포 · 악기 둘~셋 · 분위기 → 흐름(처음엔 아주 작게 → 서서히 커짐 → 마지막 장면에서 가장 크게 → 여운) → `보컬 없음, 내레이션 뒤에 깔리도록 가운데 음역은 비워 두고 잔잔하게.` 실제 가수 · 실존 곡 흉내는 쓰지 않는다.
- 이야기: 어쿠스틱 기타 · 부드러운 피아노 · 옅은 현악처럼 감정을 따라가는 곡
- 공학: 낮은 현악 · 신스 패드 · 작은 타악, 긴장이 커지다 원리가 풀리는 곳에서 넓게 열리는 곡

### 사용자가 누를 것

1. 이 채팅 입력창 「+」 → 「음악 만들기」 켜기
2. 입력창 아래 「길이」 → 「짧게」 · 「보컬」 → 「연주곡」
3. **음악 주문** 붙여 넣기 → 보내기 → 표지 그림이 나오면 ▶ 듣기
4. 표지 그림에 마우스를 올리고 「트랙 다운로드」 → `bgm`
5. 「+」 → 「음악 만들기」를 다시 눌러 끄고 "다음"

음악이 목소리보다 길어도 됩니다 — 편집 앱이 잘라 쓰고, 목소리가 나오는 동안 음악을 줄입니다.
`음악`이라고 한 단어만 보내면 음악 대신 글만 나옵니다. 꼭 주문 전체를 붙여 넣습니다.

## 9. 7단계 · 합치기 (편집 앱)

### Gemini가 줄 것

**자막용 대본** — 장면 내레이션만, `<short pause>` 같은 표시를 뺀 글(코드 블록 하나).

### 사용자가 누를 것

1. 편집 앱 https://ai.studio/apps/4482eb09-853d-4e1f-82bc-99f300f0b599 → 「This app is from another developer」가 뜨면 「Continue to the app」 ("Rate exceeded."가 뜨면 위쪽 새로고침)
2. 「재료」 탭 — 영상 조각 · 사진 · 목소리 · 음악을 **한꺼번에** 끌어다 놓기. 파일 이름 번호 순서로 타임라인에 놓입니다
3. 「자막」 탭 — 자막용 대본 붙여 넣기 → 「자막 만들기」. 틀린 글자는 왼쪽에서 고칩니다
4. ▶ 끝까지 보기. 길이는 조각 끝을 끌어서, 소리 크기는 「소리」 탭에서
5. 「내보내기」 → 「부드럽게 720p(권장)」 → 「내보내기 시작」 → 「파일 내려받기」

확인할 것: 말과 화면이 같은 내용인가 · 자막이 사진의 중요한 곳을 가리지 않나 · 음악이 목소리를 덮지 않나

## 10. 8단계 · 제목과 올리기 전 확인 (이 채팅)

### Gemini가 쓸 것

- 추천 제목 1개와 다른 제목 3개 — 궁금하게 하되 거짓으로 과장하지 않는다
- 설명 두세 줄 + "AI로 만든 장면 · 목소리 · 음악을 포함합니다" 한 줄 + 해시태그 5개 안팎
- 공학: 설명에 "이해를 돕기 위해 일부 현상을 단순화했습니다"를 더한다

### 올리기 전 세 가지

1. 사실이 맞는가 — 이름 · 숫자 · 장소를 내가 확인했는가
2. 실제 사람 얼굴 · 유명인 · 남의 음악 · 상표 · 회사 내부 자료가 없는가
3. AI로 만든 영상임을 밝혔는가 — 올리는 곳의 규칙을 따른다

## 11. 파일 이름과 폴더

주제마다 컴퓨터에 폴더 하나. 번호가 장면 순서이고, **이름순 = 영상 순서**입니다.

```text
내 주제/
  01_S01.mp4  02_S02.png  03_S03.mp4  04_S04.png      ← 장면 (영상 조각과 사진을 섞어도 됩니다)
  narration.wav  bgm.mp3                              ← 목소리 · 음악 (이름 자유)
```

공학은 영상 조각이 없는 장면에 **설명 사진**을 넣습니다.
